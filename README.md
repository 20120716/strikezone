# STRIKEZONE — 3D FPS

ブラウザで遊べる、オリジナルの低ポリゴン風3D FPSです。追加の画像・モデル・外部ライブラリを使わず、WebGLで描画します。

## プレイ

GitHub Pages が有効になったら、ここからプレイできます。

- https://20120716.github.io/strikezone/

## 操作方法

### PC
- **W / A / S / D**：移動
- **マウス**：視点操作
- **左クリック**：射撃（押している間は連射）
- **右クリック**：照準（ADS）
- **1 / 2 / 3**：武器切り替え
- **R**：リロード
- **Shift**：ダッシュ

### iPhone / iPad などのタッチ端末
- **左スティック**：移動
- **画面右側のスワイプ**：視点操作
- **FIRE**：射撃
- **AIM**：照準
- **RELOAD**：リロード
- **画面下のボタン**：武器切り替え

横画面でのプレイを推奨します。WebGL と JavaScript が必要です。

## 武器
- **VECTOR / SMG**：連射しやすい標準武器
- **BREACH / 12GA**：近距離向けショットガン
- **LONGSHOT / SR**：高威力のスナイパーライフル

## 技術
- HTML / CSS / JavaScript
- WebGL（外部ライブラリなし）
- 単一の `index.html` で動作
